## 0. Tóm tắt

Code MF-2 **không** phải viết lại: khung hồ sơ nghỉ việc (`g6-*`), phần A của `qd96-100-departure-day-access-block`,
`qd96-100-departure-block-now-mode` và K4 kho (`3128866d`) đã theo luật mới ở phần lớn bước. Phần lệch/thiếu tập trung ở **mép vòng đời** (hủy sau ngày cuối, hạn thu hồi,
trách nhiệm IT Admin phụ trách thuê bao) và **rác luật cũ** (Business Owner, approver dự phòng).
