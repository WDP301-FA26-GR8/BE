## 4. API đích

Quy ước repo: `/api/v1`, danh từ số nhiều, hành động là sub-resource, envelope `{ success, data }`, lỗi `<MODULE>.<CODE>`. Chỉ nhận trường
người dùng thực sự biết. Việc theo mốc thời gian là **hệ thống** (sweeper trong API process — ADR-0018). Route bị bỏ **xóa luôn** (§9 Q3).
**Collection** (P3, P7, P16, P17, P18, P22 `rows[]`) theo `API-LIST-DETAIL.1` (`docs/rules/api-contract.md:72`): `page`/`pageSize` (≤ 100),
schema dòng riêng; mảng lồng (P7 `oldRights[]`, P19 `vendorAdmins[]`, P23 `rightsToRevoke[]`/`openRequestsToCancel[]`/`provisioningInFlight[]`,
P25 `items[]`) có `maxItems` (quyền/Request của một người ≤ 200, admin ≤ 20, mục checklist ≤ 10). Lọc list ngoài phạm vi ⟹ rỗng; id trên path
ngoài phạm vi ⟹ 404.
