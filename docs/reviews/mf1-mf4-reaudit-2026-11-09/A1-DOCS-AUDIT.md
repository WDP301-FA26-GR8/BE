## §2. Luật chuẩn để code (MF-1 và MF-4)

Thứ tự thẩm quyền: `DEC` → `BRD` (FR, rồi `BR-MFn`) → `QT` → US AC → sơ đồ.

- Cột _Căn cứ_ ghi nguồn thắng trước, nguồn minh họa sau.
- _Tham số_ = mặc định đổi được qua `FR-8.2`; _quy tắc_ = cố định.
- Luật con có dấu ⚠ đang dính mâu thuẫn ở §3 hoặc câu mở ở §4. Khi code, dùng đúng phát biểu ghi ở bảng này.
