# Mẫu hạng mục

Đọc [quy trình](../README.md). Copy spec.md và plan.md vào docs/workspace/items/<tên-hạng-mục>/ và điền thông tin thật. Giữ tên để link nội bộ đúng.

Không cần frontmatter hay số gói tuần tự. test-plan.md tùy chọn khi kiểm thử phức tạp, liên kết từ spec/plan nếu dùng. todo.md chỉ dẫn giữ checklist ở plan, không copy sang hạng mục. Không ghi approved/passed/accepted trước bằng chứng.
