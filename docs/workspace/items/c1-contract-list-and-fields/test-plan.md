# Test plan: c1-contract-list-and-fields

[Spec](spec.md) · [Plan](plan.md). Theo `test/README.md`: integration trên PostgreSQL riêng (`pnpm test:integration -- <file>`),
e2e không DB qua `createHttpContractApp` (`pnpm test:http -- <file>`), unit cạnh file (`pnpm test -- <file>`). Không DB dùng
chung, không dữ liệu thật. Test giữ mã AC ở dòng chú thích hoặc đầu tên như các spec catalog hiện có.

Fixture chung (integration): `ContractHarness` mới trong `test/support/contract-harness.ts` (≤400 dòng) `extends
DocumentHarness` (đã có kho giả, `it1`, `finance`, `employee`, `admin`, `plan()`, `subscription()`), thêm:
`vendorOf(planId)` (SQL `plans → applications.vendor_id`), `createContract/patchContract/listContracts/contractDocuments/
contractSubscriptions/linkSubscription(subId, contractId, account)`, `legacyContract(name)` (INSERT SQL chỉ tên +
`normalized_name`), `perpetualSubscription()` (plan `LICENSED` K1 + `kind: PERPETUAL`). Trưởng phòng: `member` + head
assignment như `document-http.integration-spec.ts:29-35`. Spending Approver: chỉ ở e2e (principal có vai).
