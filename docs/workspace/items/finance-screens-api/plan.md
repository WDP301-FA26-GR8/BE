## FE mapping (đưa vào FE guide sáng mai)

- Màn 1: `GET /budgets?year=` (dòng) + `GET /budgets/summary?year=` (ô tổng); `% đã dùng = (committed + spent) / total`. Chi tiết
  phòng: `GET /budget-versions/{versionId}` + `/lines`, `GET /budget-commitments?costCenterId=&year=`.
- Màn 2: danh sách `GET /budget-proposals` · từ chối `POST /budget-proposals/{id}/return` · duyệt = lập phiên bản `POST /budget-versions`
  · trang đã duyệt = `GET /budget-versions` (nháp/trả lại) · xác nhận cuối = `POST /budget-versions/{id}/submission` → Người duyệt chi
  quyết → vào màn 1.
- Màn 3: `GET /spend-batches` → `GET /spend-batches/{id}` + `/items`. Nhãn: _Đã duyệt chi theo đợt — chờ hóa đơn_.
- Màn 4+5: `GET /budget-commitments?costCenterId=&year=&state=HELD` → mỗi dòng nút _Ghi hóa đơn_ `POST /budget-commitments/{id}/invoices`,
  xem `GET …/invoices`, _Giải phóng phần dư_ `POST …/release`. Nhãn _Đã duyệt, chưa chi_ cho `held`.
