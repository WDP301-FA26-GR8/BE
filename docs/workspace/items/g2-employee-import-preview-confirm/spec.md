## Hành vi và thiết kế

Module mới `data-import` (khung import dùng chung; file nhân sự là loại đầu tiên); ghi người **chỉ qua facade `organization`** (`createEmployeeWithPlacement`, `lookupForEmployeeImport`, `lockForEmployeeImport`). **T-28**: giao dịch xác nhận khóa theo thứ tự import `FOR UPDATE` → các phòng dùng `FOR SHARE` (theo id) → các chức vụ dùng `FOR SHARE` (theo id) → chèn người (T-11). **T-29**: so kết quả chấm dùng chuỗi chuẩn hóa thứ tự khóa (jsonb của PostgreSQL đổi thứ tự khóa).

| Operation (operationId)                                                          | Vai        | Thành công                                                                                                                    | Lỗi riêng                                                                                                                                                                          |
| -------------------------------------------------------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST /employee-imports` (`employeeImportUpload`)                                | `IT_ADMIN` | 201 `EMPLOYEE_IMPORT.UPLOADED` (`multipart/form-data`, trường `file`) bản xem trước: tóm tắt, `ignoredColumns`, `duplicateOf` | 422 `IMPORT.FILE_REQUIRED` / `FILE_EMPTY` / `FILE_NOT_TEXT` / `FILE_UNREADABLE` / `FILE_MISSING_COLUMNS` (`details.missing`) / `FILE_TOO_MANY_ROWS`; 413 quá 2 MiB                 |
| `GET /employee-imports/{id}` (`employeeImportGet`)                               | `IT_ADMIN` | 200 xem trước hoặc kết quả                                                                                                    | 404 `IMPORT.NOT_FOUND`                                                                                                                                                             |

Số dòng là dòng của file nơi dòng bắt đầu (header là dòng 1).

### Dữ liệu và migration

Migration `20261016200000_employee_import`: `employee_imports` (trạng thái `PREVIEW`/`COMPLETED`/`CANCELLED`, `preview_version`, `content_hash` SHA-256, `summary`, `result`, `confirm_key`, `expires_at`; CHECK trạng thái nhất quán — `COMPLETED` ⇔ có kết quả, thời điểm và khóa) và `employee_import_rows` (`line_number`, `cells`, `outcome`, `errors`, `differences`). Chỉ giữ các cột đã ánh xạ của file, không giữ cột thừa. Facade `organization` thêm tra cứu theo tên (phòng theo mã, chức vụ theo tên chuẩn hóa, người theo mã, chủ sở hữu email) và khóa phòng/chức vụ.

### Bảo mật và PII

Chỉ IT Admin; Finance, trưởng phòng, Employee và Super Admin bị từ chối mọi route (AC-12 `US-02-02`, `US-02-01` AC-7). Nội dung file là dữ liệu cá nhân cơ bản: không ghi vào log; ô không bao giờ được diễn giải. Tệp gốc **không** lưu; chỉ các ô đã ánh xạ ở `employee_import_rows` (xem _Giới hạn_).
