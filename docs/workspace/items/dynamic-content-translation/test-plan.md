# Test plan: dịch nội dung động EN–VI

Bổ sung cho ma trận ở [spec](spec.md#acceptance-và-kiểm-chứng): các ca header, mạng, model, đồng thời, timeout, lock và chất lượng. [Plan](plan.md) liên kết file này. Dữ liệu chỉ là giả lập; không dùng database chia sẻ, không dùng dữ liệu thật.

Cột _Spike_ ghi loại bằng chứng đã có trên code spike:

- **H**: helper test (thư viện spike, model giả).
- **RF**: runtime fake (tiến trình con giả).
- **MT**: model thật trong spike (W = Windows, L = Linux container).
- **AI**: Opus đọc và phân xử.
- **—**: chưa có.

Chưa ca nào có duyệt của người. Bằng chứng spike **không** thay test của implementation product.

- **Dọn dẹp:** thư mục model tạm được tạo và xóa trong thư mục test tạm; không ghi vào `.models/` của dev.
- **Timeout Jest** cho ca chạy model thật: ≥ 60 s ở lần nạp đầu. Trên Linux, kiểm lock cộng thêm 1,6–1,85 s mỗi chiều.
- **Lệnh:** chỉ dùng lệnh có trong `package.json`. Spike dùng `node --test` trong thư mục của nó.
- **Tài nguyên:** chỉ kill PID/container do lần chạy tạo ra và có label; không kill theo tên tiến trình.
- **Ghi kết quả:** revision, môi trường, lệnh và phần chưa kiểm chứng ở [plan](plan.md#kiểm-chứng-và-bàn-giao).
