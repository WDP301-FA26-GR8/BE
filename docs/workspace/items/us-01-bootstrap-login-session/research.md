## Nguồn chính thức đã dùng (tra 12/10/2026)

- OWASP Password Storage Cheat Sheet — Argon2id tối thiểu m=19 MiB, t=2, p=1: <https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html>
- PostgreSQL 17 — `CREATE INDEX` (hàm trong predicate phải immutable): <https://www.postgresql.org/docs/17/sql-createindex.html>; `btree_gist` (trusted): <https://www.postgresql.org/docs/17/btree-gist.html>; khóa dòng 13.3.2: <https://www.postgresql.org/docs/17/explicit-locking.html#LOCKING-ROWS>; constraint trigger: <https://www.postgresql.org/docs/17/sql-createtrigger.html>
- Node.js 24 — `readStream.setRawMode(mode)`: _"all special processing of input characters by the terminal is disabled, including echoing input characters. Ctrl+C will no longer cause a SIGINT when in this mode."_ <https://nodejs.org/docs/latest-v24.x/api/tty.html>; `readline` (`rl.question` chỉ có tùy chọn `signal`): <https://nodejs.org/docs/latest-v24.x/api/readline.html>
- NestJS — cookies với Express (`cookie-parser`, `@Res({ passthrough: true })`): <https://docs.nestjs.com/techniques/cookies>
- Express 5 — `res.clearCookie`: _"Cookie options, which should match those given to res.cookie() (excluding expires and maxAge)"_: <https://expressjs.com/en/5x/api/response>
- Gói đã cài: README `@nestjs/jwt` 11.0.2, README `jsonwebtoken` 9.0.3 (`algorithms`), `node_modules/@prisma/client/runtime/client.d.ts` và `client.js` 7.9.1 (tùy chọn và mặc định giao dịch).

## Giới hạn

- Thử nghiệm chứng minh **tương thích và hành vi API**, không chứng minh code của lát đúng; không thay test của lát.
- Không đánh giá bảo trì dài hạn của từng gói ngoài phiên bản/ngày phát hành trên registry.
- `cookie-parser` dùng không có secret: refresh token đã là bí mật ngẫu nhiên và CSDL chỉ lưu hash, không cần cookie ký.
